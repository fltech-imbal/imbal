# Expected Correct

Expected Correct is a sub-metric used in the calculation of the [Heikde Skill Score](../heikde_skill_score).

It is equal to the following:

$$
\text{Expected Correct} = expected\_true\_positive + expected\_true\_negative
$$

$expected\_true\_positive$ is defined [here](expected_true_positive) and $expected\_true\_negative$ is
defined [here](expected_true_negative).
