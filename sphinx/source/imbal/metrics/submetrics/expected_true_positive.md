# Expected True Positive

Expected True Positive, also known as chance hit, is a sub-metric used in the calculation of the
[Heikde Skill Score](../heikde_skill_score) and the [Gilbert Skill Score](../gilbert_skill_score).

It is equal to the following:

$$
\text{Expected True Positive} = \frac{(true\_positive + false\_negative)*(true\_positive + false\_positive)}{sample\_size}
$$
