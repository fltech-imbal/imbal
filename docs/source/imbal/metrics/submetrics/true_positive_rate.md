# True Positive Rate

True Positive Rate is a sub-metric used in the calculation of the [True Skill Statistic](../true_skill_statistic.md),
the [J Statistic](../j_statistic.md), and [Youden's Index](../youdens_index.md).

It is equal to the following:

$$
\text{True Positive Rate} = \frac{true\_positive}{true\_positive + false\_negative}
$$
